# Operations Logic
## Storage Construct
The accrual construct contains a set of links representing the individual water rights transfered to Platoro per diversion point (WDID) and a link that combines the storage for each WDID.

|Feature | Simulated |
|--|--|
|Water rights accrual links  | Max flow transfered - calculated with the historical data of the storage scenario factoring back in the storage charge |
|Combined storage link |    Volumentric limit for the WDID + Simulated charge loss (Channel loss)|
